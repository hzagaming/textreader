# TextReader 1.1.1

Released on August 23, 2026.

TextReader 1.1.1 adds restrained motion and clearer playback feedback without distracting from spoken content.

## Highlights

- Added short entrance, panel-reveal, status, and selection-control transitions across Popup, Side Panel, Options, and webpage controls.
- Added a dedicated loading spinner and a subtle playback-state ring so the main reader action communicates its state without relying on text alone.
- Added staggered Options sections and tactile primary-button feedback while keeping layout geometry stable.
- Extended reduced-motion handling to animation delays, durations, and iteration counts.
- Disabled the Popup reader action when the current page has no usable content connection, matching the visible unavailable-page error.
- Rechecked compact layouts, themes, accessibility state, selection responsiveness, browser TTS lifecycle, and production bundles after the motion changes.

TextReader continues to use browser/OS Web Speech only. SFX and BGM remain intentionally absent because notification sounds and background music would compete with spoken content. No remote audio, tracking, client-side credentials, or third-party secrets were added.

## Verification

- 33 automated test files with 144 passing tests, including motion-hook, panel-reveal, and loading-feedback coverage
- ESLint, full-workspace TypeScript, production build, formatting, production dependency audit, diff validation, version consistency, extension-resource integrity, and sensitive-data checks
- Isolated production-extension checks for entrance and state feedback, reduced-motion behavior, compact layouts, overflow, accessibility names, and console errors
