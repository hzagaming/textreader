# TextReader 1.1.2

Released on August 27, 2026.

TextReader 1.1.2 improves startup responsiveness, cross-surface settings safety, and browser voice recovery after a full UI, UX, motion, and audio-lifecycle audit.

## Highlights

- Registered webpage reader messaging before asynchronous settings and progress reads finish, so Popup and Side Panel controls can connect immediately after a page loads.
- Bound Popup page metadata and reader state to one captured active tab, preventing mixed titles and controls during rapid tab changes.
- Routed Popup, Side Panel, and Options writes through one background settings queue so concurrent updates no longer overwrite unrelated fields.
- Added completion watchdogs for both reader playback and voice previews. A browser voice that starts but never ends now cancels cleanly and surfaces an error instead of leaving the interface stuck; paused reading is excluded from the timeout.
- Rechecked selection startup, compact layouts, themes, reduced motion, multilingual labels, playback/preview isolation, accessibility feedback, and production extension resources.

TextReader continues to use browser/OS Web Speech only. SFX and BGM remain intentionally absent because notification sounds and background music would compete with spoken content. No remote audio, tracking, client-side credentials, or third-party secrets were added.

## Verification

- 33 automated test files with 150 passing tests, including immediate startup messaging, tab-bound Popup state, centralized settings writes, and stalled-voice recovery
- ESLint, full-workspace TypeScript, production build, formatting, production dependency audit, diff validation, version consistency, extension-resource integrity, and sensitive-data checks
- Isolated production-bundle UI checks for Popup, Side Panel, Options, voice controls, reduced-motion behavior, compact layouts, accessibility names, and console errors
