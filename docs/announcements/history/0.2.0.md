# TextReader 0.2.0

TextReader 0.2.0 completed the Phase 2 local reading experience for Chrome and Microsoft Edge.

## Highlights

- Added selected-text, main-article, and full-page reading with browser-local system voices.
- Added Mozilla Readability extraction with cleaned fallback extraction.
- Added a Side Panel document view, sentence and paragraph navigation, voice controls, themes, and reading-time estimates.
- Added sentence and paragraph webpage highlighting, saved per-page progress, Continue, and Start over.
- Added Popup, Options, context-menu, keyboard-command, multi-tab, and service-worker connection flows.

This historical release did not include remote AI voices, streaming audio, SFX, or BGM.
